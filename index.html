xTiles Dashboard Sync & Page Linking

Populate your xTiles workspace and link across pages and groups

💡 How to paste into xTiles: Select the cadence below, click "Copy xTiles Markdown", open your xTiles page, click inside any Tile block, and press Ctrl + V. xTiles automatically converts them into interactive task checkboxes and tags!
xTiles Ready-to-Paste Markdown Format: Copied to clipboard! Ready to paste into xTiles.
@ 1. Use '@' Mentions for Instant Cross-Page Backlinks

Inside any task or note in xTiles, type @ followed by the name of another page or project (e.g. @Sprint Goals, @Client Deliverables, or @Budget 2026).

This creates a two-way clickable link: clicking it instantly opens that project, and xTiles automatically tracks the backlink.

⎘ 2. Paste as Linked Page (Synchronized Across Projects)

If you want your Tasks Dashboard to exist in multiple project workspaces simultaneously:

  1. In your xTiles tab or page list, right-click your Tasks page and click Copy.
  2. Navigate to your other project workspace/group.
  3. Right-click in the tab bar and select "Paste as Linked Page".

✓ Any task you check off or edit in one place will immediately sync across all linked pages!

🗂 3. Create Subpages Inside Tiles (`/page`)

To keep each tile uncluttered while attaching extensive project documentation:

Click in any tile, type /page and press Enter. This creates a nested subpage block inside that tile (e.g. for "Monthly Budget Breakdown" or "Sprint Retrospective Notes").

📅 4. Central Aggregation: "My Planner" & "Task Collection"

Whenever you add tasks in xTiles with due dates or recurring labels, click the Task Panel icon in xTiles' left sidebar or open My Planner. All tasks from all your tiles, groups, and pages are centralized in a single filterable view!

Recommended xTiles Tile Setup:

Create a new page in xTiles called "Pulse Pro Tasks" and arrange 4 tiles side-by-side or in a 2x2 grid:

Tile 1: Daily Habits & Priorities Tasks done daily. Resets daily. Contains @daily links.
Tile 2: Weekly Sprints Sprint reviews, 1-on-1s. Contains subpages for retrospectives.
Tile 3: Monthly Milestones Finance, audits, metrics. Linked to monthly planning docs.
Tile 4: Annual OKRs Long-term vision, health, taxes. Linked to annual roadmap.
Embedding this Live Dashboard into xTiles:

If you host this project online (e.g. GitHub Pages or Vercel) or run a local server:

  1. Type /embed inside an xTiles tile.
  2. Paste the web URL of your dashboard.
  3. xTiles will render the live interactive stopwatches, history explorer, and progress rings directly inside your xTiles page!
